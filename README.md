# Codebase Dependency Visualizer

A Flask-based developer tool that analyzes Python codebases and visualizes their dependencies and architecture.

## Features

- Python AST-based code analysis
- Interactive dependency graph
- Circular dependency detection
- Codebase metrics
- Hotspot detection
- Architecture score
- Source code inspection

## Tech Stack

Python • Flask • AST • JavaScript • HTML • CSS • Cytoscape.js

## Run

```bash
pip install -r requirements.txt
python app.py
